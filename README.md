## 简介

《霓虹裂隙（NEON RIFT）》是一款俯视角霓虹风格的生存动作小游戏。你在一片持续
崩解的霓虹空间里移动，唯一的攻击手段是**冲刺——穿过敌人的身体**。敌人越密集，
越容易打出连锁击杀，但一次失误就会断掉连击并失去一格完整度。

整个游戏是**一个 `index.html` 文件**：没有构建步骤、没有框架、没有第三方库、
没有任何外部素材或网络请求。所有画面由 Canvas 2D 在运行时绘制，所有声音由
Web Audio API 实时合成。双击即可运行，也可以直接静态托管。

## 在线试玩

### ▶ https://green798.github.io/neon-rift/

浏览器直接打开即可，无需安装任何东西；手机同样可以玩（自动切换触屏操作）。

> 首次进入需**点击「开始游戏」**——浏览器要求用户操作后才允许播放声音，
> 这一步同时用于解锁 Web Audio。

**本地运行（无需任何环境）**

```text
下载 index.html → 双击用浏览器打开即可
```

也可以起一个本地静态服务（推荐，避免个别浏览器对 `file://` 的音频限制）：

```bash
# 任选其一，在 index.html 所在目录执行
python -m http.server 8000
npx serve .
```

然后访问 `http://127.0.0.1:8000/`。

## 操作方式

### 桌面端

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或 方向键，或按住鼠标左键牵引 |
| 冲刺（攻击 / 无敌位移） | `空格` 或 鼠标点击 |
| 暂停 | `P` / `Esc` |
| 开始 / 重开 | `Enter` |

### 移动端

检测到触屏（`pointer: coarse`）后自动切换操作方案：

- **拖动屏幕**任意位置：虚拟摇杆移动
- **点按 DASH 按钮**：冲刺
- DASH 按钮的**大小、透明度、位置**可在「设置」里调整（位置直接拖动按钮本身）

## 玩法与机制

### 完整度（INTEGRITY）

- 初始与上限均为 **5 格**。
- 受击扣 1 格，随后进入 **2.2 秒无敌**，并以自身为中心清除附近敌人，
  连击清零。
- **冲刺期间无敌**：冲刺既是位移也是唯一的攻击窗口 —— 这是整个战斗设计的核心。
- 场地中定时刷新**心形道具**（存活 14 秒），拾取回复 1 格。

### 连击（CHAIN）

- 每次击杀累加 CHAIN，**3.2 秒内**没有新击杀则清零。
- 得分倍率：`min(12, 1 + CHAIN × 0.25)` —— 10 连击为 3.5 倍，44 连击触顶 12 倍。
- 结算页会记录本局 **MAX CHAIN**。

### 敌人

| 类型 | 外观 | 行为 | 基础分 |
| --- | --- | --- | --- |
| `hunter` 追踪者 | 小型 | 持续缓慢追踪，转向有惯性 | 120 |
| `brute` 重装者 | 大型（半径 26） | 移动慢、体型大、难绕开；**死亡时爆裂成 2 枚碎片** | 320 |
| `lancer` 枪骑 | 中型 | 先蓄力锁定，再高速直线冲刺 | 400 |
| `shard` 碎片 | 极小型 | 由重装者死亡产生，速度快、血量薄 | 70 |

投放节奏：

- 开局仅 `hunter`；**12 秒后**开始混入 `brute`；**26 秒后**开始混入 `lancer`。
- 场地内敌人数上限 **55**。
- 每隔一段时间触发一次 **SURGE（涌潮）**，屏幕播报并成组投放敌人，间隔随
  存活时间缩短。撑得越久，节奏越密。

### 拾取

| 道具 | 效果 |
| --- | --- |
| 金色光点（mote） | 补充分数；重装者掉 3 个、枪骑 3 个、其余 1 个 |
| 心形（heart） | 回复 1 格完整度，14 秒后消失 |

### 数据持久化

全部保存在浏览器 `localStorage`，不上传任何数据：

| Key | 内容 |
| --- | --- |
| `neonrift.best` | 历史最高分 |
| `neonrift.muted` | 静音状态 |
| `neonrift.dashbtn` | 移动端 DASH 按钮的大小 / 透明度 / 位置 |

## 技术实现

| 项目 | 说明 |
| --- | --- |
| 形态 | 单文件 `index.html`（HTML + CSS + JS 全内联，约 3,190 行 / 91 KB） |
| 渲染 | Canvas 2D 即时模式；`devicePixelRatio` 上限 2 倍适配高分屏 |
| 发光 | 离屏 canvas 预渲染发光精灵并按色缓存，替代昂贵的实时 `shadowBlur` |
| 粒子 | 900 个粒子的固定对象池 + 环形索引复用，避免运行时 GC 抖动 |
| 打击感 | 命中停顿（hit-stop）+ 屏幕震动 + 冲击波 + 粒子爆发 + 闪白 + 动态暗角 |
| 音频 | Web Audio API 全程序化合成：锯齿波 55 / 82.41 / 110 Hz 低频 pad，经 LFO 调制的低通滤波；带通噪声脉冲做打击与冲刺音；**零音频文件** |
| 依赖 | 无。无框架、无第三方库、无外部字体、无 CDN、运行时不发任何网络请求 |
| 离线 | 完全离线可用 |

### 浏览器支持

需要支持 Canvas 2D 与 Web Audio 的现代浏览器：Chrome / Edge / Firefox /
Safari 的近年版本均可，移动端 Safari 与 Chrome 已适配（含安全区域内边距）。

## 已知限制

- 敌人与拾取的刷新位置依赖随机数，同一局的难度曲线存在个体差异，属设计内。
- 音效依赖浏览器自动播放策略：**必须由用户操作（点击「开始游戏」）触发**，
  否则 AudioContext 会被挂起。
- 移动端虚拟摇杆为屏幕相对拖动方案，未做物理摇杆的死区标定。
- 未提供关卡编辑、排行榜后端或存档同步 —— 本项目只做单局无尽生存。
